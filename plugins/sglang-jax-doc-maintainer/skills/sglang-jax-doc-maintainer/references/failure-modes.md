# 失败模式

遇到以下情况时输出阻塞报告，不要编辑：

- base branch 不明确。
- `gh` 不可用或未登录，且没有本地 diff 替代输入。
- private PR 无权限访问。
- diff 太大，无法安全分批分析。
- repo root 或 docs root 不存在。
- changed-files-only 语义不足。
- dirty workspace 中有未归属改动且尚未确认可安全避开冲突继续。
- 用户要求跳过确认、直接改图或新增 01-13 之外文件但未明确授权。
- 当前代码与既有文档冲突，但无法确认设计意图。
- 引用验证失败。
- docs build 失败。

报告必须包含：已完成分析、阻塞原因、当前不应编辑的原因、需要用户提供的信息。
