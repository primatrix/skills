# references

这是 references 索引。维护时保持与 `README.zh.md` 同步；中文说明以 `README.zh.md` 为准。

- `scope.md`：默认编辑范围和越界授权规则。
- `security.md`：不可信输入、敏感信息和权限边界。
- `workflow-and-safety.md`：repo discovery、确认、dirty workspace、失败处理。
- `evidence.md`：Evidence / Inference / Unknown 证据模型。
- `doc-map.md`：代码到文档召回、主文档范围、候选扩展和置信度规则。
- `doc-source-map.md`：从文档陈述回查权威代码来源的反向验证入口。
- `update-decisions.md`：更新、不更新、阻塞和越界新增的决策规则。
- `taxonomy.md`：横向架构概念和 taxonomy 规则。
- `writing-style.md`：最终中文文档写作规则。
- `validation.md`：验证命令和完成 / 阻塞报告。
- `templates.md`：输出模板；若与 `SKILL.md` 不一致，以 `SKILL.md` 为准。
- `commands.md`：常用命令模板。
- `failure-modes.md`：必须停止的失败模式。
- `review-checklist.md`：人工 review checklist。
