# 证据模型

## Evidence

可用于最终项目事实的来源：

- 当前代码。
- diff 中的代码事实。
- 测试中可验证的行为。
- 配置声明、默认值、schema、CLI 暴露。
- 既有文档中未过期的事实。
- 用户明确确认。

## Inference

合理推断可以出现在分析报告中，但不能直接写成项目事实。例：从 PR body 推断设计意图、从路径名推断模块职责、从测试名推断用户可见行为。

## Unknown

以下必须标记 unknown 或询问用户：

- 设计动机。
- 性能提升。
- 稳定性或兼容性承诺。
- 支持范围。
- 默认启用状态无法从代码确认。
- 文档陈述与代码冲突但缺少上下文。

每条拟写入最终文档的项目特定事实，都必须能回查到 Evidence。
